# 💱 Convert

Projeto desenvolvido como desafio da Rocketseat para praticar **HTML**, **CSS** e **JavaScript**.  
O objetivo é criar um **conversor de moedas** simples e funcional, que mostra o valor convertido em tempo real.

---

## 🖥️ Sobre o projeto

O **Convert** é um site que permite converter valores entre diferentes moedas.  
Ele foi criado para treinar manipulação do **DOM**, uso de **eventos em JavaScript** e boas práticas no desenvolvimento de formulários.

---

## 🚀 Tecnologias usadas

- HTML  
- CSS  
- JavaScript
